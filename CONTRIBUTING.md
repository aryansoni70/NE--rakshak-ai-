# 🤝 Contributing to NE-RAKSHAK AI

Thank you for your interest in contributing to **NE-RAKSHAK AI**! This project is built as an AI-based Smart Logistics & Accessibility Intelligence Platform for the North Eastern Region of India (MDoNER / SIH26002).

---

## 🧭 Code of Conduct

We are committed to providing a welcoming, inclusive, and professional environment for all contributors. Please treat fellow contributors with respect and maintain a constructive tone in all discussions and code reviews.

---

## 🛠️ How to Contribute

### 1. Fork & Clone the Repository
```bash
git clone https://github.com/aryansoni70/NE--rakshak-ai-.git
cd NE--rakshak-ai-
```

### 2. Create a Feature Branch
Use descriptive branch names following our naming convention:
```bash
# For new features
git checkout -b feat/satellite-sar-integration

# For bug fixes
git checkout -b fix/weather-timeout-handling

# For ML model improvements
git checkout -b ml/enhance-landslide-regressor
```

### 3. Local Development Setup
1. **Backend & ML:**
   ```bash
   python -m pip install fastapi uvicorn scikit-learn pandas numpy requests joblib httpx websockets
   python data-pipeline/generate_synthetic_data.py
   python ml/train_road_risk.py
   python ml/train_eta.py
   ```
2. **Frontend:**
   ```bash
   npm install
   npm run dev
   ```

### 4. Running Verification Tests
Before submitting a Pull Request, make sure all automated tests pass:
```bash
# Test backend endpoints
python backend/test_backend_endpoints.py

# Test frontend build
npm run build
```

## 📌 Coding Standards & Guidelines

- **Clean Typography & UI Design:** Avoid generic AI buzzwords or distracting flashy animations. Adhere to the authoritative **National Logistics & Mission Control (NDMA / MDoNER)** theme.
- **Model Explainability:** Every tactical recommendation generated by the decision engine must be traceable back to actual model outputs (risk scores, terrain slopes, or ETA deltas).
- **TypeScript Typing:** Ensure all frontend API interactions and props have explicit types defined in `frontend/src/types/index.ts`.
- **Commit Messages:** Follow standard conventional commit formats:
  - `feat: add flood inundation layer to Leaflet map`
  - `fix: resolve Open-Meteo fallback cache timeout`
  - `docs: update API endpoints table in README`

## 📬 Submitting a Pull Request (PR)

1. Commit your changes with clear, concise messages:
   ```bash
   git add .
   git commit -m "feat: your feature summary"
   ```
2. Push to your branch:
   ```bash
   git push origin feat/your-feature-name
   ```
3. Open a Pull Request on GitHub against the `main` branch.
4. Describe your changes clearly in the PR description, including test steps.
